# Benchmarks

This directory holds benchmark and comparison reports: analyses of external
products, architectures, or patterns used to inform Forge decisions.

Benchmark reports are **evidence, not requirements**. A pattern found in another
product does not become a Forge requirement because it exists elsewhere.
Adoption candidates are tracked in [`../TECHNOLOGY_RADAR.md`](../TECHNOLOGY_RADAR.md);
accepted decisions are recorded in [`../DECISIONS.md`](../DECISIONS.md).

## Contents

| Document | Scope | Status |
| --- | --- | --- |
| [`../STAGE_1_5_EXTERNAL_BENCHMARK.md`](../STAGE_1_5_EXTERNAL_BENCHMARK.md) | External architecture benchmark: publicly documented product patterns, conceptual comparison. | CONCEPTUAL ANALYSIS — proposed statuses are not approved decisions. |

## Note on location

`STAGE_1_5_EXTERNAL_BENCHMARK.md` remains at the `docs/` root because other
stage documents reference it by that path. It is listed here as the benchmark
register entry so that new benchmark reports can be added under this directory
without duplicating an index. New benchmark reports should be created here.

# Benchmarks — русская версия

Этот каталог содержит benchmark-отчёты и отчёты сравнения: анализ внешних
продуктов, архитектур или паттернов, используемый для обоснования решений Forge.

Benchmark-отчёты — это **свидетельства, а не требования**. Паттерн, найденный в
другом продукте, не становится требованием Forge только потому, что существует
где-то ещё. Кандидаты на принятие отслеживаются в
[`../TECHNOLOGY_RADAR.md`](../TECHNOLOGY_RADAR.md); принятые решения фиксируются в
[`../DECISIONS.md`](../DECISIONS.md).
