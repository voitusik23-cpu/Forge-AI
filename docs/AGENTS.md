# Planned agent roles

These roles describe the intended future system. No agents are implemented in
the initial scaffold.

- **Orchestrator** — coordinates work and routes tasks to suitable agents.
- **OpenAI/Codex** — primary coding and execution agent.
- **Claude** — independent architecture and code reviewer.
- **Gemini** — independent reasoning and large-context reviewer.
- **Grok** — adversarial testing and edge-case reviewer.
- **Reviewer** — verifies proposed changes.
- **Tester** — runs tests and validates results.

# Планируемые роли агентов — русская версия

Эти роли описывают предполагаемую будущую систему. В начальном каркасе агенты не
реализованы.

- **Orchestrator** — координирует работу и направляет задачи подходящим агентам.
- **OpenAI/Codex** — основной агент кодинга и выполнения.
- **Claude** — независимый рецензент архитектуры и кода.
- **Gemini** — независимый рецензент рассуждений и больших контекстов.
- **Grok** — рецензент адверсариального тестирования и граничных случаев.
- **Reviewer** — проверяет предложенные изменения.
- **Tester** — запускает тесты и проверяет результаты.
